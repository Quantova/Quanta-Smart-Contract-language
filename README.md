# Quanta Smart Contract Language

This repository holds the Quanta smart contract language and its compiler. Security is declared in the entry signature and proven by the compiler before a contract can exist. Source files compile to virtual machine bytecode with an embedded interface descriptor, and every classic contract exploit fails to compile. Governed by the crypto policy in the Quantova Specs repository. Commits are authored by the owner only. Dual licensed under Apache 2.0 and MIT.
